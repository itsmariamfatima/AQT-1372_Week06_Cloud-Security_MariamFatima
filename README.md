# ASTRAQUANTUM TECH – Cloud Security Practical Assessment

## 📌 Overview

This repository contains my practical work for the **ASTRAQUANTUM TECH Summer of Cybersecurity 2026** program.

The assessment focused on hands-on **Cloud Security** concepts using AWS-based security labs. The practical activities helped me understand how IAM permissions, S3 access, and cloud misconfigurations can affect the security of cloud environments.

## 🎯 Objectives

The main objectives of this practical were:

- Understand basic AWS cloud security concepts
- Enumerate IAM users and permissions
- Analyze IAM policies and access rights
- Investigate AWS S3 bucket permissions
- Identify cloud security misconfigurations
- Understand the security risks of excessive or public access
- Apply the principle of least privilege
- Practice identifying and documenting security findings

## 🧪 Labs Completed

### 1. Intro to AWS IAM Enumeration

**Platform:** Pwned Labs

This lab focused on AWS IAM enumeration and understanding the permissions assigned to an IAM user.

### Key Activities

- Identified the AWS IAM user
- Enumerated attached IAM policies
- Examined an inline S3 access policy
- Identified allowed S3 actions
- Enumerated the permitted S3 bucket
- Retrieved the lab flag

### Key Learning

This lab demonstrated the importance of **IAM least privilege** and regular review of user permissions.

---

### 2. AWS S3 Enumeration Basics

**Platform:** Pwned Labs

This lab focused on identifying security issues related to publicly accessible AWS S3 resources.

### Key Activities

- Enumerated a publicly accessible S3 bucket
- Identified exposed files
- Investigated a publicly accessible migration archive
- Analyzed the contents of the archive
- Investigated exposed cloud credentials
- Used the discovered credentials within the authorized lab environment
- Identified access to sensitive resources
- Completed the challenge

### Key Learning

This lab demonstrated how **public storage exposure, hardcoded credentials, and excessive permissions** can create significant cloud security risks.
